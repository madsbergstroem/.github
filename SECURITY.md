# Security policy

This policy applies to every repository of this account that has no `SECURITY.md` of its own.

## Reporting a vulnerability

Please don't open a public issue, pull request or discussion about it.

- If the repository's Security tab has a "Report a vulnerability" button, use that form. Only the maintainers see the report.
- If it doesn't, contact the maintainer directly through the channel you got access to the repository with.

Tell us what is affected, how to reproduce it and what an attacker could do with it. You'll get an answer within 48 hours.

## Supported versions

Fixes go into the latest release, or into the default branch for projects without releases. A repository's own `SECURITY.md` can say otherwise.

## Disclosure

Once a fix is out, we agree with you on when the details go public, and we credit you if you want.
